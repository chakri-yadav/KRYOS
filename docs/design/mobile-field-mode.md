# Mobile Field Mode

Mobile KRYOS is not the full product. It is Field Mode.

## Purpose

Field Mode exists because real life happens away from the laptop.

It should support:

- quick check
- quick add
- habit checkoff
- pulse capture

## Tabs

| Tab | Purpose |
| --- | --- |
| Today | see due tasks and carry-forward |
| Add | capture a task into Today, date, or Inbox |
| Habits | one-tap habit checkoff |
| Pulse | mood, energy, focus, arrival, one thought |

## Rules

- No full analytics.
- No roadmap editing.
- No heavy settings.
- No complex filters.
- No big charts.
- No duplicate desktop workflows.

## UX Goal

Open, act, close.
