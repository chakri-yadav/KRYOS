# Design System

KRYOS should feel premium, calm, focused, and progress-oriented.

## Visual Direction

- Professional productivity system.
- Green progress language inspired by contribution heatmaps.
- Blue for structure and trust.
- Amber for attention.
- Red for risk or destructive actions.
- Minimal decorative noise.

## Color Roles

| Role | Usage |
| --- | --- |
| Signal green | completion, progress, active success |
| Deep green | primary motivation and important progress |
| Blue | stable structure, neutral status, system trust |
| Amber | drift, partial, attention |
| Red | delete, missed, danger |
| White/surface | main panels |
| Muted gray | secondary information |

## Typography

- Use strong headings only for true page-level focus.
- Use compact headings inside cards and panels.
- Do not scale text wildly on small screens.
- No negative letter spacing.
- Prioritize scanability.

## Components

- Buttons for clear commands.
- Icon buttons for repeated utility actions.
- Chips for status.
- Progress bars for completion.
- Heatmaps for long-term consistency.
- Cards for repeated items only.
- Panels for focused sections.

## Interaction Feel

The app should feel:

- intentional
- fast
- clean
- honest
- not childish
- not overloaded
