# 0.45.9 — Journal recovery protection

- Protect local journal entries, linked records and drafts when the browser has no known cloud baseline.
- Prevent action-count recovery heuristics from silently replacing journal work.

Validation: deterministic freshness-flow simulations, full application tests and browser regression checks. No personal cloud records were written during testing.
