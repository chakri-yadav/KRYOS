# KRYOS 0.004.005

## Mission

Make effort easier to repeat for an ADHD mind by making recorded progress visible and connecting effort to guilt-free enjoyment.

## Product Boundary

- Journal remains the primary capture surface.
- Action Vault is the only persistent task system and supports assistant imports plus direct correction.
- Progress turns journal evidence into visual feedback.
- Rewards converts completed actions into transparent effort credits.
- No duplicate Today, habit-task, focus, career or redirect systems were restored.

## Credit Rule

Reviewed completed actions earn 1-5 credits using the documented effort scale. Observations earn zero. Redeeming spends available credits but does not alter lifetime completion analytics.

## Action Rule

An action exists once. Selecting Active, changing priority, or completing it updates that same record. At most three actions may be Active simultaneously.
