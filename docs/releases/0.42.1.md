# 0.42.1 — Historical activity attribution

- Attribute manual action completion to the shared selected date while preserving entry time.
- Keep routine identity and original entry time when historical totals change.
- Ignore repeated action states and unchanged routine totals.
- Pass day revisions and reusable request keys through the daily-command mutation adapter.
- Reject future activity completion while allowing planning.

Validated with 23 focused automated checks and isolated browser checks of historical updates and request replay. No cloud schema or ingestion endpoint change is required for this client correction.
