# KRYOS 0.5.3 — Career Mobile

## Release date

2026-09-25

## Product reason

Career on a phone should guide the next learning action rather than expose a
wide analytics dashboard. The user needs to know which roadmap, module, topic,
and evidence step comes next without losing the truth of the shared Career
record.

## Included

- Current roadmap command surface.
- Next unfinished evidence step and quick completion control.
- Compact deadline control and visible next milestone.
- Mobile roadmap selector and add-roadmap controls.
- Reduced mobile presentation of heatmaps, broad analytics, and full journey
  detail while preserving those views on desktop.

## Explicitly excluded

Launch, Money, Progress, Rewards, and changes to Career data behavior remain
outside this milestone.

## Data, sync, and backup impact

No new Career record type or storage key was introduced. Mobile updates the
existing roadmap, topic, checklist, confidence, and deadline records. Existing
immediate local persistence and debounced Career cloud synchronization remain
unchanged.

## Verification

- `node --check app.js` passed.
- `git diff --check` passed.
- Desktop Career rendering and roadmap handlers were preserved.
- iPhone 15 Plus Safari visual, completion, refresh, and sync QA remains
  required before publishing the GitHub Release.

## Known limitations

Full roadmap journey and portfolio analytics remain desktop-first by design.
They can be revisited after real mobile usage identifies a specific need.
