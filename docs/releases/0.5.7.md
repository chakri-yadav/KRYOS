# KRYOS 0.5.7 — Mobile Freshness

Release date: 2026-09-25

## Product reason

The iPhone experience must feel current immediately. A premium shell is not useful when a returning session quietly displays an older browser copy.

## User problem

Opening or resuming KRYOS could show stale data because the app restored local state without checking Supabase, while Safari could also restore a frozen page from its back-forward cache.

## Included scope

- Check signed-in cloud data at launch and after returning to the foreground.
- Provide a visible manual refresh control in the mobile header.
- Apply a newer remote Foundation, Career, Tasks, or Journal block only when the local block has not also changed.
- Preserve local data and report a conflict when both copies changed.
- Reload pages restored from Safari's back-forward cache.
- Upgrade the iPhone shell with `viewport-fit=cover`, safe-area spacing, compact status controls, a floating icon-led tab bar, touch feedback, and calmer card treatment.

## Explicit exclusions

- No field-level conflict merge.
- No mobile Launch, Money, Progress, or Rewards destination.
- No data migration or schema change.
- No redesign of desktop navigation.

## Data, sync, and backup impact

Existing records and storage keys are unchanged. Freshness uses the current block timestamps and sync schema. Remote content is never allowed to silently replace a locally changed block. Existing export/import remains the rollback path.

## Acceptance criteria

- iPhone 15 Plus safe areas and Home Indicator remain unobstructed.
- A signed-in launch checks for newer safe cloud blocks.
- Returning after more than one minute checks again.
- A manual refresh provides visible activity feedback.
- Safari back-forward restoration cannot leave a frozen stale screen.
- Offline use remains available and local data remains intact.
- All four mobile destinations retain at least 44-point controls.

## QA performed

- Static JavaScript syntax validation.
- Full automated test suite.
- Cache-key deployment-order validation.
- Responsive source inspection at the 430-point iPhone 15 Plus breakpoint.

## Known limitations

Block conflicts require review in Settings; KRYOS does not yet offer field-level merge. Automatic freshness requires an existing signed-in Supabase session.

## Next milestone

Mobile conflict-resolution controls with explicit keep-local, keep-cloud, and export-first choices.
