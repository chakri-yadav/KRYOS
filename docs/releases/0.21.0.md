# KRYOS 0.21.0 — Resume interview speaking roadmap

## Purpose

Help the user speak clearly, confidently, and truthfully about the claims on
their resume in technical interviews. This is a communication and claim-defense
roadmap, not a broad technical curriculum.

## Modules

1. Claim truth and ownership boundaries.
2. A concise spoken story for each claim.
3. Technical explanation at the depth needed to defend the claim.
4. Interviewer follow-up practice for ownership, metrics, choices, and limits.
5. Mock speaking practice, feedback, and retrieval.

The private audit remains a reference source. Its assumptions, illustrative
architectures, and unknowns must not be represented as confirmed work history.
No private resume text or employer-specific details are included in the public
application code.

## Data and QA

- Adds `roadmap-resume-interview-speaking` once through Career migration.
- Preserves unrelated Career roadmaps and activity history; stable checklist
  completion survives reconciliation.
- Automated checks cover scope, progression, unique IDs, idempotency, and data
  preservation.
- No database schema change. A signed-in app persists through ordinary
  revision-checked Career sync.
