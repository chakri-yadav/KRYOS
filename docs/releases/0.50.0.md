# Scoped analytics and compact evidence

19 October 2026 · local 0.33.0 / hosted 0.50.0.

## Product reason and scope

Make displayed application totals traceable while keeping the daily workspace
readable. This distribution is the hosted aggregate release 0.50.0.
See [metric and interaction contract](../design/analytics-evidence.md).

Local Progress opens exact contributing submissions, including reapplications.
Hosted Progress opens received dated snapshots, including confirmed zeroes;
unknown dates do not become zero. Three headline measures, labelled reporting
periods, optional source details and equivalent tables reduce default density.
Invalid ranges preserve the previous chart. Record return retains range and focus.
Source panels preserve disclosure and distinguish saved, pending and recovery state.

Counts-only downloads exclude job/contact/document fields. Downloading does not
transfer to cloud or earn points. Existing stage breakdown and trend comparisons
remain available as optional details.

## Acceptance and verification

228 local / 338 public automated checks pass. Synthetic tests cover correction,
void, repeated submission, grouped-chart/table/export parity, explicit follow-up
IDs, overlap maximum, corrected zero and unconfirmed receipt presentation.
Disposable-service and isolated hosted browser checks exercise custom dates,
invalid input, drilldown, record return, exact counts export, source disclosure,
focus retention, reduced motion and five widths (320–1440 pixels).
Screenshots reviewed. No production imports or cloud writes are used for testing.

## Data, synchronization and recovery

No schema, reward, curriculum, production record or automatic handoff change.
Marketing records/files stay local; hosted uses approved aggregate receipts only.
Source rollback preserves compatible history/document readers and current data.
Keep a verified database/files backup independently of the source release.

## Known limits and next milestone

Desktop browser acceptance does not claim a physical-phone or full screen-reader
audit. Snapshots describe the saved source revision, not a live laptop connection.
Reporting preferences live in the current browser session. Next: reward, money
and settings clarity using existing domain rules.
