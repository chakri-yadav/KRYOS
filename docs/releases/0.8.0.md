# KRYOS 0.8.0 — Money Command

## Product reason

The prior Money page showed one friend balance and contact history. It could not clearly show the separate Amex card shares and direct reimbursement that the founder needs for a factual conversation.

## User-facing changes

- A command view places the next follow-up, verified figures, and statement status before detailed analytics.
- A focused call brief displays the exact reimbursement, informal request, card share, last contact, and recorded promise.
- A dated checkpoint records Amex balance, both card shares, exact direct reimbursement, and any separate informal request.

## Data and sync

The optional checkpoint is stored inside the existing Personal `tasks.money` sync block. Existing Money records remain intact. A checkpoint is rejected unless the two card shares equal the statement balance to the cent; if covered and reimbursed amounts are entered, they must equal the exact direct amount. No private figures are committed to GitHub.

## Verification

- `node --check money.js`
- `node --test tests/*.test.cjs tests/assistant-ingestion.test.mjs`: 58 passed.
- `node tests/money-browser.cjs`: checkpoint validation, reconciliation, and call-focus navigation passed in Edge using the bundled Playwright runtime.

## Known limits

The checkpoint is dated and does not automatically recalculate from transaction-level statement lines. A future Money ledger milestone will add transaction import, payment-source allocation, and statement-by-statement reconciliation.
