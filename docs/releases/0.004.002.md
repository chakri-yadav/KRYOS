# KRYOS 0.004.002

## Summary
Progress now connects today's outcome, the current week, long-term history and a selected reward.

## User-facing changes
- Daily outcome completion bar with a five-minute start action.
- Monday-to-Sunday status strip, completed outcome total and personal-best scheduled streak.
- Separate daily outcome, timed focus and journal-domain heatmaps; 12 or 52 weeks.
- Selected reward progress uses existing available VP; lifetime VP stays separate.
- Focus history is collapsed by default. Responsive controls and reduced-motion support.

## Data rules
Streaks use the entire recorded outcome history, not the visible calendar range. Scheduled rest does not break a streak. Today remains open until the day ends. Journal completions do not automatically complete the daily outcome. Journal-reported time and timer time remain separate because they may overlap. A single completion is never awarded extra VP by this view.

Reward selection is saved in the existing profile-aware life object within the task block. Existing backup and manual cloud sync include it. No database migration.

## Verification
Unit checks cover historical streaks, schedule changes, separate journal activity and reward selection. Browser checks cover persistence, controls, populated and empty views, desktop/mobile layout, and runtime errors.

## Limitations
No AI-derived health scores, automatic deduplication of independently entered records, or new reward pricing. The domain calendar indicates whether a completion was recorded, not adherence against a configured habit schedule. Cross-device sync remains manual.
