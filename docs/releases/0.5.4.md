# KRYOS 0.5.4 — Rhythm Mobile

## Release date

2026-09-25

## Product reason

Rhythm must make daily foundations easy to record on a phone. The mobile user
needs a calm checklist for nourishment, care, spiritual practice, and recovery,
not a dense visualization that competes with the act of showing up.

## Included

- Compact Rhythm command surface and daily foundation status.
- Touch-safe Nourish, Care, Spirit, and hydration controls.
- Weekly maintenance goals with reachable mobile increment controls.
- Mobile target/settings controls with readable input sizing.
- Desktop-first treatment for the 28-day constellation, seven-day pulse, and
  insight panel.

## Explicitly excluded

Launch, Money, Progress, Rewards, and new Rhythm data behavior remain outside
this milestone.

## Data, sync, and backup impact

No new Rhythm event type, storage key, Supabase table, or backup format was
introduced. Mobile updates existing source events and targets. Local-first
persistence and existing task-block cloud synchronization remain unchanged.

## Verification

- `node --check app.js` passed.
- `git diff --check` passed.
- Desktop Rhythm rendering and event handlers were preserved.
- iPhone 15 Plus Safari visual, quick-entry, refresh, and sync QA remains
  required before publishing the GitHub Release.

## Known limitations

Advanced Rhythm visualizations are intentionally desktop-first and hidden from
the mobile primary flow.
