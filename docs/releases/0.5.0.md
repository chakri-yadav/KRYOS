# KRYOS 0.5.0 — Mobile Foundation

## Release date

2026-09-25

## Product reason

KRYOS is designed for one ADHD user who needs fast, low-noise access to the
next correct action on an iPhone. The desktop navigation exposes more areas
than are useful during mobile execution, so the mobile shell must be focused
without creating a second data system.

## Included

- Four stable mobile destinations: Inner Command, Actions, Career, and Rhythm.
- Safe-area-aware body, content, header, and bottom-navigation spacing.
- Sticky mobile context header.
- Touch-safe navigation controls with visible focus states.
- Mobile overflow protection and a dedicated bottom-navigation surface.
- Canonical `0.5.0` asset cache keys for GitHub Pages.

## Explicitly excluded

Launch, Money, Progress, and Rewards remain outside primary mobile navigation.
Their desktop routes and shared records are unchanged.

## Data, sync, and backup impact

No new record type, storage key, Supabase table, or backup format was added.
Mobile uses the existing shared KRYOS state. Local-first persistence, cloud
status, lock behavior, and backup logic remain unchanged.

## Acceptance criteria

- The mobile shell has exactly four primary destinations.
- The active destination is visually and semantically identifiable.
- The bottom navigation respects the Home Indicator safe area.
- The top context respects the Dynamic Island safe area.
- The page cannot horizontally overflow at the target mobile width.
- Desktop navigation remains unchanged.
- Existing page routes continue to render from the shared state.

## Verification

- JavaScript syntax checked with `node --check`.
- `git diff --check` completed without whitespace errors.
- Browser-based iPhone visual verification remains required before publishing
  the GitHub Release; the local workstation currently lacks its Python preview
  runtime.

## Known limitations

Feature-specific mobile layouts are not included yet. Inner Command, Actions,
Career, and Rhythm still require their own focused mobile milestones.
