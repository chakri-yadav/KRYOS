# KRYOS 0.5.6 — Mobile Quality

## Release date

2026-09-25

## Product reason

The mobile workflow must remain calm and usable under real ADHD conditions:
different text sizes, reduced motion preferences, touch input, keyboard entry,
and repeated one-handed use.

## Included

- Visible keyboard focus states across mobile controls.
- Text-size and input sizing that avoids unnecessary iPhone zoom.
- Reduced-motion support for mobile transitions and animations.
- Clear touch feedback and manipulation behavior.
- Preserved safe-area and four-destination navigation behavior.

## Explicitly excluded

No new product workflow, data model, sync behavior, backup format, or desktop
analytics changes were introduced.

## Verification

- All repository test files pass: API roadmap, Career deadlines, deployment,
  DSA roadmap, journal imports, Progress, and Rewards.
- `node --check app.js` passed.
- `git diff --check` passed.
- Deployment ordering now verifies the canonical `0.5.6` asset keys.
- Mobile-specific styles remain scoped to responsive contexts or accessibility
  preferences.
- Final iPhone 15 Plus Safari visual, Dynamic Type, VoiceOver, offline, sync,
  backup, and lock QA remains required before publishing the GitHub Release.

## Known limitations

The repository still needs a real device/browser QA pass and a working local
preview runtime before this mobile line can be considered production-verified.

## Next milestone

Post-mobile QA and GitHub release packaging. No new feature version should be
assigned until the complete `0.5.x` line passes that verification.
