# 0.45.0 — Historical review queue

- Surface elapsed days awaiting initial review or correction confirmation.
- Open any queued date directly in its guided review from the daily workspace or Progress.
- Show recent dates first, with the full queue available on demand.
- Remove confirmed dates from the queue while preserving calendar access.
- Keep preparation, current and future days outside the catch-up queue.

Validation: 23 targeted tests and browser verification of queue navigation in both application variants. Queue generation is read-only and uses existing review records.
