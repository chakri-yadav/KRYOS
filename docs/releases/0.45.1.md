# 0.45.1 — Career and launch date attribution

- Attribute Career checklist completion evidence to the selected day, preserving entry timestamps.
- Preserve explicit topic and module completion dates for deadline calculations.
- Avoid repeated completion evidence for the same roadmap checklist identity.
- Default Launch forms and weekly activity summaries to the selected date.
- Validate completed Launch activity against the actual operating day and retain occurrence and entry timestamps.

Validation: 25 focused checks plus browser verification of historical Launch entry and the existing integrated review flow in both application variants.
