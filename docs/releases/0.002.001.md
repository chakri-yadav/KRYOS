# KRYOS 0.002.001 - Profile Login Correction

Date: 2026-07-06

## Summary

KRYOS now treats Personal and Demo as credential-based profiles. Demo no longer appears as a Settings switch. The demo profile is opened from the lock screen using the fixed demo PIN.

## User-Facing Changes

- Personal credentials open the private workspace.
- Demo credentials open the safe showcase profile.
- Demo profile is seeded automatically with sample data.
- Settings no longer contains a Personal/Demo switch.
- Demo Settings shows that demo credentials are fixed for showcase access.

## Technical/Data Changes

- Added fixed demo profile PIN handling.
- Demo security is configured automatically.
- Personal credential matching runs before demo credential matching.
- Removed old Settings mode-switch event path.
- Kept mode-aware storage keys and active-profile backup/import/reset behavior.

## QA Performed

- `app.js` syntax check passed.
- Static scan confirmed old Settings switch hooks are gone.
- Mocked login simulation confirmed PIN `9619` opens Demo and creates a demo session.
- Browser QA passed on an isolated local test origin:
  - throwaway Personal PIN opened Personal
  - demo PIN `9619` opened Demo
  - Demo Career, Today, Habits, Journal, Progress, and Settings showed sample/demo data
  - Personal login returned to Personal without the Demo badge
  - active-profile backup labels and export notices appeared correctly

## Known Risks

- Browser visual QA still needs a reliable local browser session.
- Demo PIN is a local showcase credential, not server authentication.
