# KRYOS 0.10.0 — Statement evidence

## Product reason

The Money page now turns verified issuer statements into a private visual history so balance movement and interest pressure are understandable at a glance.

## User-facing changes

- Balance and actual-interest trend chart.
- Latest balance, cumulative interest, recent monthly pressure, and balance reduction tiles.
- Minimum-payment pressure ring and a clearly labeled directional payoff estimate.
- Six-cycle evidence strip with APR, interest, and minimum due.

## Technical and data changes

- Added a deduplicated `money.statementCycles` collection to the private Tasks block.
- Added `money.statement.import` to revision-safe assistant ingestion.
- Raw statements and statement text remain outside GitHub and browser storage.

## QA

- Pure Money engine and assistant projection tests.
- Browser Money workflow and visual presence test.
- Production cloud round trip and Pages verification required before release tagging.

## Known risks

- Payoff months are a directional estimate, not an issuer payoff quote.
- PDF extraction still requires assistant review before private ingestion.
