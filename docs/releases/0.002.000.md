# KRYOS 0.002.000 - Private Mode Separation

Date: 2026-07-06

## Summary

KRYOS now separates private daily use from safe demo/showcase use. Personal mode keeps the existing local data keys. Demo mode uses separate prefixed keys and seeded sample data.

## User-Facing Changes

- Settings includes a Personal/Demo data space selector.
- Demo Mode loads safe sample data for Foundation, Career, Today, Habits, Journal, Progress, and Settings.
- Demo Mode shows a persistent badge.
- Demo sample data can be rebuilt from Settings.
- Backup, import, and reset now apply only to the active space.

## Technical/Data Changes

- Added global active mode key: `kryos-account-mode-v1`.
- Personal mode remains backward compatible with base keys.
- Demo mode stores data under `kryos-demo-*` keys.
- Backup format moved to version `3`.
- Backup export includes active account mode metadata.
- Security session state is mode-aware.

## QA Performed

- `app.js` syntax check passed.
- Static storage scan confirmed only account-mode helpers access raw local storage.
- Mocked browser startup confirmed Demo creates only `kryos-demo-*` data keys.

## Known Risks

- Browser visual QA still needs a reliable local browser session.
- Demo export/import behavior still needs manual end-to-end testing.
- Cloud sync is not implemented.
