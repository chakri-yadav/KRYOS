# KRYOS 0.004.003

## Summary

KRYOS can now receive reviewed progress records maintained by the assistant without daily setup, JSON pasting or a separate cloud login.

## Behavior

- `assistant-data.js` contains an encrypted reviewed progress package.
- Each package has a permanent ID and is imported only once into the personal profile.
- Demo mode never consumes personal assistant packages.
- The normal local lock remains unchanged.
- A KRYOS day begins at 7:00 AM and ends at 6:59 AM the next civil day.

## Privacy Boundary

The repository is public, so progress packages are encrypted with the configured personal credential hash before publication. Raw notebook images, full private journal text, credentials and secrets must never be added. The four-digit local PIN is convenience-grade protection, not high-security encryption.

## Validation

- Nine Node data tests passed.
- Desktop and mobile browser workflows passed with no runtime errors.
- Mobile layouts passed horizontal-overflow checks at 390 px and 320 px widths.
