# KRYOS 0.5.5 — Mobile Reliability

## Release date

2026-09-25

## Product reason

Mobile work is not reliable if the user cannot lock the app, inspect sync
status, create a backup, or recover the active profile from the phone. These
are safety services and must remain reachable without polluting primary mobile
navigation.

## Included

- Mobile Settings utility button in the top context area.
- Mobile-safe utility sizing for settings, cloud state, and lock context.
- Continued access to active-profile backup/import, privacy, lock, and sync
  recovery through the existing Settings view.
- No change to security, backup, storage, or cloud data ownership.

## Explicitly excluded

New synchronization conflict resolution, new backup formats, and feature-page
redesigns remain outside this milestone.

## Verification

- `node --check app.js` passed.
- `git diff --check` passed.
- Existing Settings, security, backup, and sync handlers were preserved.
- iPhone 15 Plus Safari lock, settings, backup, refresh, offline, and cloud
  failure QA remains required before publishing the GitHub Release.

## Known limitations

The mobile utility opens the existing full Settings surface. A later release
may add a smaller recovery sheet if real use proves the full surface too heavy.
