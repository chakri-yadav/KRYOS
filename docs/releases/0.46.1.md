# 0.46.1 — Consistent submission evidence

Released 19 October 2026.

## Purpose

Different projections previously disagreed about test records, retained dates on
unsubmitted jobs and repeated job identities across dates. A shared pure
projection now defines compatible dated counts for evidence and aggregate export.
The laptop analytics uses the same projection for totals and drilldown.

## Data and scope

No migration, record update, reward-rule change or cloud statistics handoff.
The hosted distribution continues to accept approved aggregate snapshots only.
Local files and job records stay on the laptop. The exporter rejects impossible
dates and missing identities no longer form a fabricated submission.

Conflicting legacy dates retain the existing per-date export contract and are
diagnosed internally for the later submission-history milestone. Status changes
still follow that legacy eligibility contract; explicit history is future work.

## Verification

Local suite: 193 passing tests. Hosted suite: 308 passing tests. New fixtures
cover count parity, exclusions, canonical identity, deterministic duplicate
selection, immutable input, disposable SQLite export and aggregate field scope.
Local workspace and evidence browser checks passed, including date navigation,
five-width workspace reflow and refresh. Production data was not changed.

## Recovery

Restore the prior distribution source package if necessary; no database rollback
is required. Existing source/data backups remain separate. See desktop release
acceptance for the recovery procedure.

Next milestone: deterministic actionable work selection.
