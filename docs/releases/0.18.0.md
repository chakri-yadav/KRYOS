# KRYOS 0.18.0 — Book-based SDE system design roadmap

## Summary

Adds the approved general SDE system-design learning path to Career. It follows
the supplied System Design Interview book in chapter order, teaches concepts
before practice, and keeps the Amazon-specific roadmap out of scope.

## User-facing changes

- 17 modules: book Chapters 1–15, cross-cutting reliability/operations, and
  final interview-practice synthesis.
- Each module contains learning, book-study, and/or practice checklists.
- Web crawler, video service, and file storage/sync are clearly marked optional
  stretch modules; Chapter 16 remains optional further reading.
- No fixed due dates and no pre-completed work.

## Technical and data changes

- Versioned, idempotent Career migration adds `roadmap-system-design-book`.
- A pre-existing roadmap with the same title is preserved; the imported roadmap
  then receives a disambiguated title.
- Existing Career activity history is unchanged. Checklist completion is keyed
  by stable checklist IDs and retained if this roadmap is reconciled.
- Migration runs on local Career initialization and after fresh cloud Career
  data is pulled. The normal revision-checked Career sync persists it to the
  Personal Supabase account.
- No Supabase schema change or direct personal-data write is required.

## QA

- Dedicated checks cover chapter sequence, module content, unique identifiers,
  optional-stretch labeling, migration idempotency, collision safety, and
  progress preservation.
- Full project test suite and GitHub Pages deployment checks run before merge.

## Known risks / limits

- First cloud persistence requires opening the signed-in released app and
  allowing its normal Career sync to complete.
- This roadmap deliberately excludes Amazon-specific interview preparation.
