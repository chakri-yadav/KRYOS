# KRYOS 0.004.000 - Directed Attention

Date: 2026-09-17

## Release Intent

This release removes KRYOS from the category of broad self-improvement dashboards. Its primary job is now behavioral routing: decide, start, redirect, recover, and ship evidence.

## User-Facing Changes

- Today permits one outcome and no more than two support tasks.
- Focus separates Build from Analyze and offers five- or twenty-five-minute starts.
- Redirect provides short action protocols instead of open-ended reflection.
- Rewards ties explicit privileges to earned Alignment XP.
- Project permits one active breakthrough project and records shipped artifacts.
- Weekly Review summarizes evidence without becoming another editable planner.

## Behavioral Rules

- Analysis does not count as building.
- Points cannot be typed or corrected directly.
- A repeated completion event cannot award points twice.
- Slips do not subtract points or erase progress.
- Recovery actions remain available on low-capacity days.
- The interface gives the next action priority over explanatory copy.

## Technical Notes

- New records are stored under `tasks.behavior` in the existing task storage block.
- The existing export/import and Supabase block sync include the new data automatically.
- Legacy feature data is preserved and can be migrated later; this release does not delete it.
