# Learning context and launch continuity

19 October 2026 · local 0.31.0 / hosted 0.49.0.

## Outcome

Career remembers module/topic context and expanded module/detail panels in this
browser. Preference keys separate workspace, account mode, hosted account and
roadmap. Continue opens the exact existing topic and next unfinished core step;
deleted contexts fall back safely. Optional work remains optional.

Context does not copy or complete tasks, change curriculum, earn rewards or sync
between independent Career stores. Note drafts survive background renders and
navigation in memory. Existing change/blur saves still own persistence. Reload
restores saved notes, not uncommitted typing; the UI explains this distinction
and warns on reload while typing remains uncommitted.

Launch offers one selected market, mock or speaking focus per date for the
current session. Speaking opens the existing self-rehearsal form, not a second
activity type or duplicate reward. Application evidence links to existing dated
counts and source details. The shared router owns Marketing open/return controls
in both builds, including the previously disconnected hosted entry button.
