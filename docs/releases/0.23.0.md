Replace the prior book-based System Design Roadmap with the exact HLD / SYSTEM
DESIGN — SDE-2 structure provided for Career. This release imports the source
structure; it does not substitute a new syllabus.

## Included source structure

- The five unnumbered depth levels, L4 through L0.
- All 14 numbered modules, preserving module titles, topic wording and level,
  optional/stretch priorities, and chapter/practice prompts.

  groups: Core, Short Concept Designs, and Optional.

  section, matching their placement in the supplied structure.

## Data and migration

title. Do not add another System Design roadmap. Preserve matching completed
checks, unrelated Career roadmaps, and historical activity. No schema change;
normal revision-checked Career sync persists the migration when the signed-in
release is opened.

practice/final section content, stable IDs, in-place migration, matching progress
