# 0.45.11 — Explicit block conflict resolution

- Add browser-to-cloud and cloud-to-browser choices for one reviewed daily-records or legacy-journal block.
- Require paired download and an explicit block-replacement acknowledgement.
- Persist and verify a profile-scoped recovery backup before replacement; allow downloading the last recovery backup later.
- Revalidate reviewed browser/cloud snapshots, account identity and schema compatibility.
- Use revision-and-timestamp conditional cloud updates with read-back verification; never retry unconditionally.
- Pause overlapping automatic task writes during resolution and preserve new browser edits.
- Leave unrelated blocks, local Marketing and Career untouched.

Validation: 268 automated checks, isolated browser tests for both directions, and an authenticated zero-match conditional-update endpoint check that left the live block unchanged. Real phone/laptop acceptance remains separate.
