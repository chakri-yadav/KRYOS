# 0.003.000 - Free Sync Foundation

Date: 2026-07-06

## Summary

KRYOS now has the first product-grade sync foundation: documented Supabase schema, auth boundary, conflict rules, and a Settings readiness panel. Remote sync is still disabled.

## User-Facing Changes

- Settings shows cross-device sync readiness.
- Settings shows whether Personal or Demo is eligible for sync testing.
- Settings includes local readiness and dry-run buttons.
- The Supabase connection action is visible but disabled until a real project is configured.
- Version identity now shows `0.003.000`.

## Technical Changes

- Added profile-aware local sync state.
- Added sync payload preview that includes safe blocks only.
- Excluded PIN/recovery/session data from the sync payload preview.
- Added local readiness and dry-run actions.
- Added Supabase schema, auth model, and conflict rule documentation.

## QA Performed

- `app.js` syntax check.
- Static review of sync-safe and sync-excluded storage keys.
- Browser smoke check of Settings on desktop width.
- Browser smoke check of Settings on narrow mobile width with no horizontal overflow.
- Settings readiness action confirmed Personal sync stays blocked.

## Known Risks

- No real Supabase project is connected yet.
- No cross-device round trip has been tested.
- Conflict detection is specified but not connected to a backend.
- Personal sync must stay blocked until Demo sync is proven.
