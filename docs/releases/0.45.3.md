# 0.45.3 — Dated journal drafts and financial entry

- Default journal capture and completed-record counts to the shared selected day.
- Preserve separate journal drafts for each date, including legacy draft text.
- Clear only the saved date's draft after journal capture.
- Default dated financial entry forms to the shared selected day and reject future completed records.
- Explain that financial balances and account status remain current.

Validation: 26 targeted checks and browser coverage in both variants for draft isolation, historical journal capture and financial form defaults. Tests used synthetic records in isolated browser storage.
