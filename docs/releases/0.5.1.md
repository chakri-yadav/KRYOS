# KRYOS 0.5.1 — Inner Command Mobile

## Release date

2026-09-25

## Product reason

The phone should help the user contain attention, acknowledge the current
state, and capture one honest record without making the desktop journal layout
smaller and harder to use.

## Included

- Compact purpose and Inner Command presentation.
- Focused containment covenant layout with safe-area-aware spacing.
- Mobile-friendly return guidance and daily evidence context.
- Mobile journal capture with touch-safe date, text, and save controls.
- Compact evidence timeline cards below the primary capture surface.
- No changes to journal, containment, or sync data ownership.

## Explicitly excluded

Actions, Career, Rhythm, Launch, Money, Progress, and Rewards feature redesigns
are deferred to their own milestones.

## Verification

- `node --check app.js` passed.
- `git diff --check` passed.
- Desktop routes and shared records were preserved.
- iPhone 15 Plus Safari visual QA remains required before publishing the GitHub
  Release because the local preview runtime is unavailable.

## Known limitations

The mobile timeline remains available but is not yet a dedicated filtered
history surface. Further progressive disclosure will be evaluated after real
use.
