# 0.28.1 — Daily Command visual refinement

The selected Daily Command design places must-do tasks beside the daily outline, keeps purpose readable, and separates battle review and journey history. Preparation has no visible start-hour label; Day 1 shows its Saturday date. Quantity targets use direct totals and increment controls. Open panels, unsaved form fields and reading position survive updates. Corrections use a focused dialog.

The shared Actions identity, battle engine, historical records and existing reward rules are unchanged. Verified with renderer and engine checks plus local browser inspection.
