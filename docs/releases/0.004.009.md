# KRYOS 0.004.009

## Summary

Actions is now a premium, focused command surface. The underlying Action Vault remains unchanged: one persistent record per commitment, four statuses, optional deadlines and a strict three-action active limit.

## Visual System

- Strong page hierarchy with open and due-soon context.
- Dark active-field command band with a three-slot capacity signal.
- Compact, stable task rows with domain, priority and human deadline states.
- Progressive disclosure for new actions and a dedicated modal editor.
- Responsive layouts with no horizontal overflow at tested desktop and compact widths.

## Persistence

- Every change is written to browser storage immediately.
- When a Supabase session exists, the task block is pushed after a short debounce.
- Repeated changes collapse into one write and another write is queued if data changes during an in-flight request.
- A failed cloud request does not discard the local change.

## Validation

- Seventeen data tests pass.
- The personal-profile browser workflow passes unlock, encrypted imports, add, edit, deadline update, refresh persistence, Progress and Rewards checks.
- Desktop and compact visual checks pass without horizontal overflow.
