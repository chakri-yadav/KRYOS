# KRYOS 0.5.8 — Mobile Career Read Mode

Release date: 2026-09-25

## Product reason

Mobile simplification must reduce visual noise, not remove the information required to understand and execute a career roadmap.

## User problem

The previous mobile release hid the selected roadmap detail. It exposed only a next step and summary panels, preventing the founder from reading modules and topics or toggling any checklist item other than the current recommendation.

## Included scope

- Restore the complete selected-roadmap read experience on mobile.
- Show roadmap purpose, target date, modules, topics, confidence, module and topic deadlines, progress, and all checklist items.
- Allow every checklist item to be marked complete or incomplete using the same shared Career record and sync path as desktop.
- Add a compact section navigator for Now, Deadlines, Roadmaps, and Full plan.
- Keep roadmap selection available on mobile.
- Improve visual hierarchy, spacing, progress presentation, completed states, and touch targets.

## Explicit exclusions

- Roadmap creation, renaming, restructuring, and deletion remain desktop editing work.
- Weekly heatmaps and broad analytics remain reduced on mobile.
- No storage model or Supabase schema change.

## Data, sync, and backup impact

No new mobile data is created. Completion toggles update the existing Career block, save locally first, and use the existing debounced Supabase synchronization. Existing backup and restore behavior is unchanged.

## Acceptance criteria

- The complete selected roadmap is readable at 430 by 932 points.
- Every visible checklist item can be completed and uncompleted.
- A completion survives reload and triggers the existing cloud-save state.
- Desktop Career editing remains available and unchanged.
- Mobile roadmap creation and destructive editing controls are absent.
- No horizontal overflow occurs in any Career section.
- Primary mobile controls provide at least a 44-point hit region.

## QA performed

- JavaScript syntax validation and the full automated test suite.
- Desktop Career regression test through the existing browser workflow.
- iPhone 15 Plus viewport testing across Career overview, section navigation, full roadmap reading, completion, uncompletion, and reload persistence.
- Runtime error and horizontal-overflow inspection.

## Known limitations

Large roadmaps remain vertically long by design because their complete read content is now available. A future release may introduce remembered module disclosure states without hiding information by default.

## Next milestone

Audit and refine the remaining Command, Actions, and Rhythm mobile details against the same full-function, low-noise standard.
