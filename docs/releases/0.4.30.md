# KRYOS 0.4.30 — Multi-day Journal and Containment Import

## Release date

2026-09-25

## Product reason

KRYOS must preserve truthful, backdated evidence from reviewed journal records
without inventing completion, duration, meaning, or containment outcomes.

## Included

- Imported the reviewed September 20–24 journal records.
- Added backdated health, spiritual, and activity evidence.
- Added assistant-import support for 45-day containment kept/breach records.
- Recorded the reported astrology and social-feed breach honestly.
- Preserved anxiety as a return signal rather than automatically treating it as
  a containment breach.

## Data and sync impact

The release uses existing Journal, Rhythm, Inner Command, and task-block data
structures. No Supabase schema migration is required. Imports remain
idempotent and evidence is committed locally before cloud synchronization.

## Acceptance criteria

- Reviewed packages import once and cannot duplicate on refresh.
- Backdated records retain their journal date.
- Observations do not become completed actions without explicit evidence.
- Containment kept/breach states remain auditable.
- Existing personal data remains isolated from Demo data.

## QA and known limitations

Import, progress, reward, roadmap, deadline, and deployment tests are present
in `tests/`. Full local execution currently requires repairing the workstation
Node/npm installation. Cloud round trips still require configured Supabase
schema and credentials.
