# KRYOS 0.17.0 — Manual Marketing role capture

## What changed

Marketing now supports adding one job posting directly, in addition to importing a batch. The form captures company and title (required), source URL, location, salary, work arrangement, sponsorship, posted date, responsibilities, requirements, full captured posting text, unknowns to verify, and an initial tracking status.

On save, the role opens in the existing detail view. Application status can be updated there, and the owner can add dates, contact information, résumé version, notes, and supporting files.

## Batch behavior

- A manually added role joins the selected non-demo batch.
- If the selected batch is fictional demo data, KRYOS creates a separate real `Manually added roles` batch.
- If no batch exists, the same real batch is created.
- Existing imported batch data is not overwritten.

## Storage and privacy

Marketing continues to use browser-local storage. Manual job data and attachments are not cloud-synced or included in KRYOS JSON backups. This release does not alter Supabase or personal KRYOS data.
