# KRYOS 0.22.1 — Resume mastery curriculum fidelity

## Product reason

Complete the import of the supplied Resume Interview Mastery System. Release
0.22.0 had the five layers and most technical modules, but omitted the explicit
claim-to-module crosswalk and several of the source's operating rules.

## Included

- Map the six Role A and five Role B resume bullets to the shared technical
  modules, using private placeholders rather than publishing employer names.
- Add the exact five-pass practice cadence: understand, closed-notes explanation,
  five attack questions, a 90-second linked-bullet answer, and random follow-ups;
  then revisit later through spaced recall.
- Make all four source depth tiers usable: Must Speak, Must Understand, Awareness
  Only, and Do Not Study for this Resume.
- Add the stated mastery standard: explain naturally through interruption,
  assumption challenges, and scenario changes.
- Add a private prompt for the resume chronology and coherent role-level system
  pictures. Exact employer/date/work-history details remain outside shared code.

## Data and synchronization

The existing `roadmap-resume-interview-speaking` record upgrades in place. Other
Career roadmaps, activity history, and exact matching checklist completion are
preserved. No schema change. The signed-in app persists the migration through
normal revision-checked Career sync when opened.

## QA and limits

Automated tests cover curriculum sections, crosswalk, idempotent in-place
migration, progress preservation, and cache-busted deployment references. The
Personal cloud write is not considered complete until the signed-in release
loads and Career sync reports success.
