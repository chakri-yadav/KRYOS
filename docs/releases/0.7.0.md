# KRYOS 0.7.0 — Devi Sadhana and Automatic Rewards

Production release date: 2026-09-26.

## Product reason

KRYOS now turns truthful daily evidence into a low-friction identity-building system for the founder's 48-day Devi Sadhana. The system keeps visible daily foundations while allowing the assistant bridge to translate spoken or written reports into the existing Personal data model.

## User-facing changes

- Inner Command runs from September 26 through November 12 as a 48-day Devi Sadhana.
- Rhythm shows meals, protein, supplements, 3 L water, skincare, spiritual practices, exercise, hair care, and groceries.
- Rewards calculate automatically from independent evidence lanes and gentle, capped boundary deductions.
- Career, Launch, articulation, exercise, hair-care, and grocery consistency gates award bounded bonuses.
- The reward catalog includes food enjoyment, information/video time, music, initiated conversation, movie night, and the important initiated call.

## Technical and data changes

- Reward rule version 3 activates by operating date and leaves historical calculations unchanged.
- Current assessments are recalculated from source evidence and use stable daily and weekly ledger identifiers.
- Assistant ingestion accepts the current Rhythm habit set, including face wash, without changing the ownership of Personal task or Career blocks.
- Explicit reopen operations support truthful Rhythm, Action, and Career checklist corrections; derived rewards recalculate from the remaining evidence.
- Browser assets use the `0.7.0` cache key.

## Acceptance and release decision

- The complete automated suite passed before release.
- The production GitHub Pages build and Supabase ingestion function were already deployed and inspected without runtime errors.
- The owner explicitly waived an additional fabricated or personal-data workflow test for this release.

## Known limitations

- The assistant bridge is local to the configured owner machine.
- Free-tier Supabase does not provide independent scheduled database backups.
- Mobile visual refinement remains deferred and is not part of this release.
