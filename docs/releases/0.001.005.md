# Release 0.001.005 - Private Stabilization

Date: 2026-07-06

## Summary

This release stabilizes KRYOS as a private local-first product and adds the first company-level documentation system.

## User-Facing Changes

- Settings now shows KRYOS version identity, release stage, release date, backup version, release notes, and next milestone.
- Career roadmap editing is now deliberate through one roadmap-level icon.
- Career checklist text is read-only unless editing the roadmap.
- Today no longer shows duplicate unscheduled task views.
- Mobile layout has safer spacing and overflow behavior.
- Backup/export is more complete.
- Lock behavior is more trustworthy after refresh.

## Technical Changes

- Backup version moved to `2`.
- Backup includes UI state.
- Import clears active security session.
- Local date key handling avoids timezone shift.
- Manual lock cannot be bypassed by refresh in manual-lock-only mode.

## Documentation Added

- product docs
- design docs
- architecture docs
- decision records
- QA plan
- agile workflow
- GitHub issue templates
