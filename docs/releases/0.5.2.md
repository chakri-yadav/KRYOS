# KRYOS 0.5.2 — Actions Mobile

## Release date

2026-09-25

## Product reason

The phone must keep persistent commitments visible without turning the Action
Vault into a dense desktop task board. The user needs to see what is active,
choose a status, and record the smallest next action with one hand.

## Included

- Touch-safe active-capacity command surface.
- Horizontally scrollable status filters with stable labels and counts.
- Mobile-friendly new-action form controls.
- Larger completion, status, and edit targets.
- Mobile-sized edit dialog with safe viewport height.
- Existing deadlines, priorities, next actions, and cloud-state feedback.

## Explicitly excluded

Career, Rhythm, Launch, Money, Progress, Rewards, and new Action data behavior
remain outside this milestone.

## Data, sync, and backup impact

No new Action record type or storage key was introduced. Mobile updates the
existing Action Vault record. Local saves remain immediate and the existing
debounced task-block cloud synchronization remains responsible for cloud sync.

## Verification

- `node --check app.js` passed.
- `git diff --check` passed.
- Desktop Action Vault rendering and shared event handlers were preserved.
- iPhone 15 Plus Safari visual and persistence QA remains required before
  publishing the GitHub Release.

## Known limitations

The Action Vault still uses the existing status filter model. A future release
may add more progressive disclosure after real mobile use identifies friction.
