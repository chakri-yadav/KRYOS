# KRYOS 0.20.0 — SDE-2 Interview Debugging roadmap

## Summary

Adds an interview-focused debugging learning path to Career for general SDE-2
roles. It complements DSA practice rather than becoming a separate production
engineering curriculum.

## Structure

1. Trace code and locate the first wrong state.
2. Reproduce and minimize the failure.
3. Test applicable boundaries and verify the fix.
4. Debug and explain reasoning in an interview-style setting.
5. Repeat the workflow in ordinary one-problem DSA sessions and capture brief
   evidence: bug pattern, first incorrect state, minimal fix, regression case.

No Amazon-specific hiring material, Leadership Principles, production/on-call
debugging, arbitrary deadline, or guaranteed interview-readiness claim is added.

## Data and QA

- One-time idempotent migration adds `roadmap-sde2-debugging-interview` to Career.
- Existing roadmaps and activity are retained; stable checklist completion is
  retained if the roadmap is reconciled.
- Automated checks verify scope, module progression, unique IDs, idempotency,
  and existing-data preservation.
- No Supabase schema change. A signed-in app session applies normal
  revision-checked Career sync after deployment.
