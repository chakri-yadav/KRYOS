# Rejected Or Deferred Ideas

This file protects KRYOS from becoming messy.

## Full Mobile App

Status: deferred.

Reason:

Mobile should be Field Mode first. Full desktop-level controls on mobile will create clutter.

## Sync Before Local Trust

Status: rejected for now.

Reason:

Sync multiplies mistakes. Local data must be stable first.

## Analytics On Every Page

Status: rejected.

Reason:

Progress owns analytics. Other pages may show small status signals but should not duplicate analytics dashboards.

## Job Application Tracker

Status: rejected for current product scope.

Reason:

KRYOS is about inner alignment, execution, habits, journaling, and progress. Job applications can be tasks or career notes, not a dedicated tracker.

## Editable Career Roadmap Everywhere

Status: rejected.

Reason:

Career should feel like a visual roadmap. Editing should be deliberate through one roadmap editor.
