# KRYOS Demo Walkthrough

Use this script only with the Demo profile. Do not show Personal data.

## Goal

Explain KRYOS in under three minutes as a private operating system for consistency, career progress, habits, journal containment, and evidence-based review.

## Opening

KRYOS is a local-first personal operating system. It is not just a todo list. It connects why I started, what I must do today, recurring habits, daily reflection, and progress analytics into one private system.

## Profile Boundary

KRYOS has separate Personal and Demo profiles. Personal uses private credentials and real data. Demo opens with demo credentials and contains safe sample data for walkthroughs.

## Career

Show Career first.

Say:

Career is roadmap-based. I can manually build DSA, system design, and product roadmaps. Progress is checklist-driven, and the app shows completion, activity, and streak evidence without turning the roadmap into a noisy spreadsheet.

## Today

Show Today.

Say:

Today is the execution cockpit. It handles dated tasks, quick tasks, carry-forward, and domain separation. The point is to keep the day organized without mixing every life category into one messy list.

## Habits

Show Habits.

Say:

Habits are for recurring discipline and visual motivation. KRYOS tracks done, partial, missed, pace, and consistency so I can see behavior over time instead of relying on mood.

## Journal

Show Journal.

Say:

Journal is for mind containment. It has daily pulse, truth filter, shutdown, and tomorrow top three. The purpose is to close the day honestly and prevent mental clutter from carrying forward.

## Progress

Show Progress.

Say:

Progress is read-only. It does not create new work. It reads Career, Today, Habits, and Journal data to show evidence, patterns, streaks, and recovery signals.

## Settings

Show Settings.

Say:

Settings holds privacy, local backup, import, reset, version identity, and active profile information. KRYOS is still private and local-first, with sync planned only after the data model is trusted.

## Close

KRYOS is being built like a long-term product, but the first user is me. The goal is to prove that a personal system can be private, structured, emotionally useful, and technically disciplined before anything public happens.
