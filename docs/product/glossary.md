# Glossary

## KRYOS

The private inner-alignment operating system.

## Foundation

The why, vows, principles, strengths, weaknesses, and return protocol.

## Field Mode

The simplified mobile mode for quick input and checkoff.

## Career Day

A day where at least one career roadmap checklist item is completed.

## Carry-Forward

A missed task moved forward so it does not disappear.

## Truth Filter

A journal tool for separating emotional thought from stricter truth and next action.

## Shutdown

End-of-day reflection that closes the day and prepares tomorrow.

## Containment

The degree to which the day's mental loops, truth filter, shutdown, and tasks are resolved.

## Demo Mode

Future safe account mode with fake data for interviews and product demos.

## Personal Mode

Future private account mode for real personal data.
