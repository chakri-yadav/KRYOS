# Feature Map

This document defines what each feature owns.

## Foundation

Purpose:

- define why KRYOS exists
- store vows
- store do and don't principles
- document strengths and weaknesses
- provide return protocol after drift

Does not own:

- task execution
- analytics
- career checklist progress

## Career

Purpose:

- create roadmaps
- create modules, topics, and checklist items
- complete checklist items
- log career activity days

Rules:

- roadmaps are visual by default
- one pencil opens roadmap editing
- checklist completion is fast
- planning alone does not count as career progress

## Today

Purpose:

- show due tasks
- show carry-forward work
- capture new tasks
- complete, miss, partial, carry, or start tasks

Does not own:

- full habit analytics
- career roadmap editing
- journal reflection

## Habits

Purpose:

- track recurring routines
- show matrix, streaks, strength, pace, and drift causes
- share task records with Today

Does not own:

- one-off task management
- journal shutdown

## Journal

Purpose:

- arrive before reacting
- capture mental state
- mind dump
- truth filter
- shutdown review
- next-day top 3

Does not own:

- progress charts
- roadmap structure

## Progress

Purpose:

- read from Today, Habits, Journal, and Career
- show weekly consistency
- show streaks, heatmaps, domain progress, and reviews

Rule:

- Progress must not require separate manual input.

## Settings

Purpose:

- privacy lock
- inactivity lock
- privacy mode
- export/import
- reset

Future:

- profile-aware backup/import/reset
- sync status

## Field Mode

Purpose:

- mobile quick check
- quick add
- habit checkoff
- pulse capture

Rule:

- Field Mode must stay small.
