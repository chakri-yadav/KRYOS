# Project Board Setup

Use this document to create the KRYOS GitHub Project.

## Project Name

```text
KRYOS Product OS
```

## Views

### 1. Roadmap

Purpose:

- show phases and major epics

Group by:

- target version

### 2. Current Sprint

Purpose:

- show what is actively being built

Filter:

- status is Ready, In Progress, Review, or QA

### 3. Bugs

Purpose:

- protect daily trust

Filter:

- type is Bug

### 4. Architecture

Purpose:

- track data, sync, security, and structure decisions

Filter:

- area is Architecture

### 5. Release Readiness

Purpose:

- confirm version is ready

Filter:

- target version is current release

## Fields

| Field | Values |
| --- | --- |
| Status | Inbox, Ready, In Progress, Review, QA, Done, Deferred |
| Type | Epic, Feature, Task, Bug, Design, Architecture, Documentation |
| Area | Foundation, Career, Today, Habits, Journal, Progress, Settings, Field Mode, Data Space, Docs, Architecture |
| Priority | P0, P1, P2, P3 |
| Version | `0.001.x`, `0.002.x`, `0.003.x` |
| Risk | Low, Medium, High |

## Rule

Every issue must have:

- type
- area
- priority
- version target
- done criteria
