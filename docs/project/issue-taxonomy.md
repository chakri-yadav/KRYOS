# Issue Taxonomy

Use this naming structure for KRYOS work.

## Epic Naming

```text
Epic: Phase 2 - Personal And Demo Separation
```

## Feature Naming

```text
Feature: Add Demo Mode seed data
```

## Task Naming

```text
Task: Separate local storage keys by account mode
```

## Bug Naming

```text
Bug: Manual lock opens after refresh
```

## Design Naming

```text
Design: Replace text edit buttons with icon controls
```

## Architecture Naming

```text
Architecture: Define sync block schema
```

## Priority Meaning

| Priority | Meaning |
| --- | --- |
| P0 | Blocks daily use or privacy |
| P1 | Important for current phase |
| P2 | Useful improvement |
| P3 | Later polish |
