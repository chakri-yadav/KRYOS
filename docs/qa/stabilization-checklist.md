# Stabilization Checklist

Use this checklist before moving from `0.001.x` to `0.002.x`.

## Data Trust

- [ ] Foundation saves correctly.
- [ ] Career saves correctly.
- [ ] Today saves correctly.
- [ ] Habits save correctly.
- [ ] Journal saves correctly.
- [ ] Progress reads from real records.
- [ ] Settings save correctly.

## Refresh Trust

- [ ] Current page persists.
- [ ] Selected roadmap persists.
- [ ] Selected dates persist.
- [ ] Selected habit persists.
- [ ] Manual lock persists through refresh.
- [ ] Auto-lock does not trigger too aggressively.

## Export/Import Trust

- [ ] Backup exports all required data.
- [ ] Backup imports into a clean browser.
- [ ] Import clears stale session.
- [ ] Import does not mix old and new data.

## UX Trust

- [ ] No duplicate visible task views.
- [ ] Career roadmap is visual by default.
- [ ] One edit icon controls roadmap editing.
- [ ] Mobile Field Mode stays simple.
- [ ] No obvious overlap on mobile.

## Release Readiness

- [ ] Changelog updated.
- [ ] Version file updated.
- [ ] Release note created.
- [ ] Known limitations listed.
