# ADR-0002: Mobile Field Mode

Status: accepted

Date: 2026-07-06

## Context

The user needs mobile access because daily life happens outside the laptop.

However, making the full desktop experience fit on mobile would create a complicated and unpleasant product.

## Decision

Mobile KRYOS is Field Mode.

It supports:

- Today
- Add
- Habits
- Pulse

It does not support:

- full analytics
- career roadmap editing
- heavy settings
- large charts

## Consequences

Positive:

- faster mobile use
- cleaner mental model
- less clutter
- better chance of daily use

Negative:

- some desktop features are unavailable on mobile
- users must use desktop for planning and review
