# KRYOS Roadmap

This roadmap is ordered by product trust, not excitement. The goal is fast progress without creating a messy system.

## Phase 1 - Local Trust

Target version: `0.001.x`

- Stabilize local saves.
- Keep refresh/session behavior predictable.
- Clean duplicated task views.
- Keep mobile simple.
- Keep export/import trustworthy.
- Document product decisions.

Status: in progress.

## Phase 2 - Personal And Demo Separation

Target version: `0.002.x`

- Add Personal mode.
- Add Demo mode.
- Open Demo from demo credentials at the lock screen.
- Separate storage keys by mode.
- Add demo seed data.
- Keep active-profile backup/import/reset behavior.
- Prevent personal data from leaking into demo exports.

Status: shipped in `0.002.001`; demo polish remains in Phase 5.

## Phase 3 - Free Sync Foundation

Target version: `0.003.x`

- Choose Supabase Free as first backend candidate.
- Keep the app local-first.
- Add account identity.
- Add block-level sync.
- Add last-synced status.
- Keep secrets out of sync until the security model is clear.

Status: planned.

## Phase 4 - Daily Operating System Refinement

Target version: `0.004.x`

- Improve Today as the execution cockpit.
- Improve Habits as a consistency engine.
- Improve Journal as mind containment.
- Keep Progress read-only and evidence-based.
- Add better personal bests and weekly review.

Status: planned.

## Phase 5 - Interview And Demo Readiness

Target version: `0.005.x`

- Polish Demo mode.
- Add product walkthrough.
- Add screenshots.
- Add architecture diagrams.
- Prepare GitHub project board.
- Keep personal data private.

Status: planned.

## Later Public-Level Vision

Target version: future private lines before `1.000.000`

- Multi-user architecture.
- Stronger privacy model.
- Real backend.
- Offline-first sync.
- Data export standards.
- Design system maturity.
- Contributor onboarding.
