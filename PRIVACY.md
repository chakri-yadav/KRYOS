# Privacy Policy For Private Development

KRYOS is private-first.

## Data Types

KRYOS can contain:

- habits
- tasks
- career roadmaps
- journal entries
- mood, focus, energy, and state data
- spiritual reflection
- personal strengths and weaknesses
- private progress history

## Current Storage

Data is stored locally in the browser using local storage.

## Sharing Rule

The private personal account should never be used for interviews, demos, public screenshots, or open source seed data.

## Demo Requirement

Before showing KRYOS publicly or in interviews, build Demo mode with:

- fake sample data
- no real journal content
- no real spiritual/private notes
- no real credentials
- visible Demo Mode badge
- separate export/import behavior

## Public Repository Rule

A public repository may include:

- source code
- documentation
- demo seed data
- screenshots with fake data

A public repository must not include:

- real local storage exports
- personal backups
- personal screenshots
- real journal entries
